# Unix

## Unix 란?
- UNIX는 원래 “운영체제 이름”이었음
    - 1970년대 벨 연구소에서 만들어짐
    - 목적: 멀티유저 + 멀티태스킹 시스템
    - 지금 우리가 쓰는 OS 개념 대부분이 여기서 나옴
- UNIX = 개념 / 표준 / 사상

## Unix 핵심 철학
- 모든 것은 파일이다
- 작은 프로그램 하나가 한 가지 일만 잘한다
    - ls, grep, awk, sed
- 파이프로 연결한다
    ```zsh
    ps aux | grep java | awk '{print $2}'
    ```
    - 이 사상 덕분에 쉘, 배치, 자동화, 서버 운영이 강력해짐
